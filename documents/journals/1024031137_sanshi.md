# SmartLib Error Journal

## `INVALID_LOGIN_CREDENTIALS`

Firebase rejected the ESP32's sign-in because the email or password in
the sketch did not match the account created for the board in Firebase
Authentication.

## `bad request (400)`

The sign-in request from the board was refused because one of its
settings was wrong, so the ESP32 never got permission to write to the
database.

## `Token status: error`

The board could not get or refresh its Firebase sign-in token, so every
write to `sensors/irX` was blocked even though WiFi was connected.
