# SmartLib Error Journal

## `Firebase_ESP_Client.h: No such file or directory`

The sketch would not compile because the Firebase ESP Client library was
not installed in the Arduino IDE, so the include at the top of the code
could not be found.

## `SSL internals timed out!`

The ESP32 connected to WiFi but could not finish the secure handshake
with Firebase in time, so no sensor values were being written to the
database.

## `Failed to initialize the SSL layer`

The board could not set up its secure connection to Firebase at startup,
which stopped it from sending any readings until it was reset and
reconnected.
